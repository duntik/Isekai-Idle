# Isekai Idle

Браузерная incremental-игра о новой жизни в фэнтезийном мире, вдохновлённая Kittens Game, Evolve и жанром исекай. Мир и персонажи оригинальные.

## Играть

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в этой папке. Сборка и установка пакетов не нужны. Интернет нужен только для необязательных шрифтов Google; предусмотрены системные шрифты.

Начните со сбора древесины и ягод. Постройте лесной сад для еды, затем дома и назначьте жителей на добычу. Лесопилки и святилища производят ресурсы автоматически. Приключения дают золото и ману. Накопите 100 маны для первого перерождения: каждая душа даёт постоянные +10% к производству и ручному сбору.

Прогресс сохраняется в localStorage каждые 10 секунд и при закрытии страницы. Офлайн-производство ограничено восемью часами. Сохранения привязаны к браузеру и адресу сайта; экспортируйте JSON для переноса или резервной копии. Импорт и перерождение требуют подтверждения.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите ветку `main` и папку `/ (root)`, затем Save. После публикации адрес: https://duntik.github.io/Isekai-Idle/ .
